# 固定出口的远端集群槽

远端槽复用原生集群 SSH、Docker、凭据同步和调度。开启此功能后，远端 `kin-egress` 经每槽独立的 SSH 回环监听连接控制面的出口守卫。守卫仍负责核对批准的 IP、阻断和锁存；节点不直接连接订阅代理，也不回退到宿主出口。

## 启用与边界

默认关闭。可设置 `KIN_CLUSTER_GUARDED_EGRESS=1`，或者在原生 `SettingsRepo` 中将 `cluster_guarded_egress` 设为布尔值 `true`。环境变量优先；其他显式环境值禁用此功能。该开关允许远端 Claude 槽使用已经配置强校验的订阅代理，不更改代理绑定上限，不接受新的出口 IP，也不解除已有锁存。Codex 强校验槽仍不受支持。

节点 SSH 主机指纹须预先核验，节点允许 SSH 回环远程转发且能运行原生 Docker/iptables。每槽监听只绑定 `127.0.0.1`，端口由槽 ID 确定；碰撞或占用报错，不另找出口。每条新连接重新读取守卫状态。SSH 断开、守卫异常或转发不可用时连接失败；重连只恢复原监听，不执行 `rearm`。

节点内槽保持独立 HOME、凭据目录、网络和资源限制。原生远端凭据同步以远端轮换后的凭据为准；只有显式导入才推送新凭据，禁止用旧快照覆盖。Cookie 导入通过控制面已批准的守卫出口。远端官方 CC bootstrap 返回 `remote_unsupported`，不能将其描述成官方 CC 安装成功；实际数据面需单独验收。

远端内核健康请求穿过 SSH。请求前探测、等待空闲槽、watchdog、面板详情和诊断共用 3 秒预算；本地槽仍使用各自原有短超时。等待空闲槽时，单次探测也不能超过剩余等待时间。健康超时不等于出口 IP 变化；该预算不解除出口锁存，也不重放模型请求。节点本身休眠或离线仍需恢复节点。

## 上线检查

1. 对照[受控升级流程](guarded-upgrade.md)排空请求。主网关重启会触发控制面守卫锁存；恢复必须取得相应授权并逐个确认原 IP。
2. 用原生接口绑定代理、启动远端槽。首次启动会通过 SFTP 传输运行程序；高延迟链路可能超过管理请求超时。先核查槽状态、远端临时文件和容器，不重复提交启动或导入。
3. 在实际槽内通过两个 HTTPS 服务核对出口，检查 DNS。仅对尚未授权的新槽短暂停止其出口 helper，确认断网后不能直连，恢复后出口仍相同。不能用控制面查询代替槽内验收。
4. 验证账号身份、HOME、模型白名单、每槽并发和独立 key。真实 JSON/SSE 请求使用新意图，不重放不确定或已计费请求。读取终帧及 HTTP EOF，核对唯一 attempt、终量和下游计费后再加入共享池。
5. 记录实际观察窗口、节点资源和旧槽状态。短时成功不等于永久稳定；故障期间维持原有锁存规则。

## 回退

先停用涉及远端槽及其下游调度，再关闭开关并恢复源码。仅关闭开关不是既有 SSH 流的即时断开开关。控制面重启按受控升级流程恢复原槽；不回灌账本、账号凭据或订阅状态，不删除守卫状态文件。

使用容器源码覆盖部署时须保存文件清单及摘要。旧镜像重新创建会丢失覆盖文件；正式重建应包含本功能、已有 Fable 防护和其他线上修复，再按同一流程验收。
